# My-First-Number-Pad
This is the build your own Hackpad, following the Hackpad mission from Stardance. 

# Overveiw

My-First-Number-Pad is a 10 switch key macropad with a OLED display, and a rotary switch/encoder. I designed this as my first project on stardance, a Hack Club program, where I have learned how to design my own macropad.

# **Features:**

- An EC11 Rotary Encoder Switch: controls volume and mute settings

* 10 Cherry MX style keys

+ SSD1306 OLED module, 0.91 inch, 128x32, I2C

- Customized case, plate, PCB
